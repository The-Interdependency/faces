# Lineament

Isolate, retrieve, and describe faces.

- **Field card** — ninety seconds, top of the head down. Skin is named on the Monk Skin Tone Scale (MST-1–MST-10).
- **Drill** — isolated line plates, left and right three-quarter views, spaced retrieval.
- **Atlas** — every term by region.
- **Time / recall** — encoding window vs. hit rate.

Skin tone is a published colour step, not a racial category.
